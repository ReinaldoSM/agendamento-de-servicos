# Sistema de Agendamento

Projeto desenvolvido como parte de um desafio técnico para vaga de programação Front-End.

O objetivo do projeto é criar uma interface de agendamento, permitindo a seleção de datas e interação com os usuários através de uma experiência simples e intuitiva.

---

## 💻 Como executar o projeto localmente

### 1. Clone o repositório

```bash
git clone -b King https://github.com/ReinaldoSM/agendamento-de-servicos.git
```

### 2. Acesse a pasta do projeto

```bash
cd agendamento-de-servicos
```

### 3. Execute o projeto

Abra o arquivo:

```bash
index.html
```

diretamente no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.

---

## 🚀 Tecnologias utilizadas

- **HTML5**  
  Utilizado para estruturação das páginas e organização dos elementos.

- **CSS3**  
  Utilizado para estilização da interface, responsividade, organização dos componentes e criação de uma experiência visual agradável.

- **JavaScript (ES6+)**  
  Utilizado para criar as interações da aplicação, manipulação do DOM, criação dinâmica dos elementos, seleção de datas e controle das funcionalidades.

## 🧠 Decisões técnicas adotadas

Durante o desenvolvimento, algumas decisões foram tomadas para manter o projeto organizado e facilitar futuras melhorias:

- Utilização de HTML semântico para melhorar a estrutura e manutenção do código;
- Separação das responsabilidades entre HTML, CSS e JavaScript;
- Uso de JavaScript para criação dinâmica dos elementos de seleção de datas, evitando informações fixas diretamente no HTML;
- Manipulação do DOM para atualizar informações da interface conforme as ações do usuário;
- Organização dos estilos utilizando classes específicas para facilitar ajustes e manutenção;
- Busca por uma interface simples, responsiva e com boa experiência de uso.
